# اتصال پروژه

تنظیم عملیاتی `backend.json` توسط [skill setup](../skill/product-workflow-setup/SKILL.md) از نام واقعی انتخاب‌شدهٔ Backend ساخته می‌شود. Backend همواره دایرکتوری همسایه با مسیر `../<BackendName>` است؛ access فقط read-only و محل مستندسازی فنی product-workflow است.

این راهنمای ثابت داخل بستهٔ طراحی است؛ `backend.json` وضعیت پروژه است و از manifest طراحی و inventory ثابت بیرون می‌ماند. نام نمونه در قالب، اتصال واقعی نمی‌سازد. قرارداد کامل در [setup پروژه](../docs/16-project-setup.md) است.
