# پرونده‌های واقعی

از [انتخاب تیم](../workflows/00-team-entry.md) شروع کنید و [برد گردش مستندات](board.json) را ببینید. فعلاً هیچ پروندهٔ واقعی ثبت نشده است؛ صف محصول، QA و فنی خالی است. مثال‌های `examples/` و طراحی خودِ این مجموعه، پروندهٔ آمادهٔ تیم‌ها نیستند.

برای نیاز تازهٔ محصول، پس از دریافت شرح، I01 و [راهنمای قالب‌ها](../templates/README.md) اجرا می‌شوند. برای QA و فنی، کاربر یک پروندهٔ واجد شرایط را انتخاب می‌کند؛ درخواست تکراری ساخته نمی‌شود. هر پرونده یک کارت در board.json و tracking، journal و مدارک نسخهٔ خودش را دارد. وضعیت جاری فقط در کارت JSON است و tracking صرفاً تاریخچه و اصلاحیه‌ها را نگه می‌دارد. Coordinator پس از هر تحویل یا برگشت و پیش از نمایش، برد را با این مدارک تطبیق می‌دهد.

[قرارداد برد JSON](../docs/07-board-json.md) و [قالب کارت](../templates/shared/board-card.json) مرجع ثبت‌اند. جدول برد فقط هنگام نمایش به کاربر از JSON ساخته می‌شود؛ فایل Markdown برد جداگانه نداریم.
