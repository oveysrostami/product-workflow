# وضعیت جاری ماژول‌ها

این بخش نمای آخرین **طرح تأییدشده** هر ماژول Backend است. در تحویل اولیهٔ این بخش هیچ ماژول واقعی منتشر نشده است؛ نمونه‌های Backend یا مثال OTP بدون پرونده و G-T معتبر به این بخش وارد نمی‌شوند.

برای خواندن یک ماژول، از `modules/<module-slug>/README.md` شروع کنید. این ورودی به نسخهٔ جاری در `revisions/<revision-id>/README.md` می‌رسد؛ همان پوشه شرح کامل و تجمعی ماژول را دارد. خواندن تاریخچهٔ requestها برای فهم رفتار فعلی لازم نیست. `current.json` نسخه و digest جاری را مشخص می‌کند؛ نسخه‌های پیشین محفوظ‌اند.

وضعیت اجرای کد، مستقل از طرح، در `implementation/` همان ماژول با revision و evidence واقعی نگه‌داری می‌شود. نبود شاهد، «نامشخص» است؛ تأیید طراحی به معنی پیاده‌سازی یا انتشار نیست.

[قرارداد کتابخانهٔ ماژول‌ها](../docs/10-module-library.md) محل حقیقت، مالکیت، انتشار پس از G-T و ثبت شواهد پیاده‌سازی را تعریف می‌کند. [قالب سند کامل ماژول](../templates/modules/README.md) و [طرح snapshot](../templates/modules/snapshot-plan.json) ورودی نگارش‌اند.
